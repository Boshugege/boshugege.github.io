## 代码

```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

## 数学公式

行内 $e^{i\theta}=\cos\theta+i\sin\theta$，独立公式：

$$
\int_0^{\infty} e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}
$$

## 图片

普通图片放在文章目录里，用相对路径：`![说明](./image.jpg)`。

带说明文字的图片：

```mdx
<Figure caption="图片下方的说明">
![替代文字](./image.jpg)
</Figure>
```

左右对比（手机上自动上下排列），两张图写在相邻两行：

```mdx
<Compare labels={["之前", "之后"]} caption="可选的总说明">
![之前](./before.jpg)
![之后](./after.jpg)
</Compare>
```
